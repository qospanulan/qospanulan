#### qoldanba: real work experience for IT students

"No job without experience, no experience without a job." qoldanba gives student teams a startup-level project and runs it like a real IT company:

- a university picks projects from a catalog and forms teams;
- each team gets a GitHub repo from a starter template, its own server with auto-deploy, and a Linear board with a ready sprint plan;
- **Sophia**, an AI mentor, reviews pull requests against the task's acceptance criteria;
- one Keycloak for sign-in across all my products.

FastAPI (hexagonal architecture) · Keycloak · Coolify · GitHub App & Linear APIs · Claude · Angular / React. *In pilot with universities.*
Open starter projects: [cargo-template-backend-fastapi](https://github.com/DevUMRA/cargo-template-backend-fastapi), [kassa-template-backend-django](https://github.com/DevUMRA/kassa-template-backend-django).
